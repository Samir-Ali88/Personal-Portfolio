# SOLO — Personal Portfolio

A responsive, dark night-sky personal portfolio website built with **HTML5**, **Tailwind CSS**, custom CSS, and **Vanilla JavaScript**[cite: 11].

🌐 **Live Site:** [https://samir-ali88.github.io/Personal-Portfolio/](https://samir-ali88.github.io/Personal-Portfolio/)

---

## Features

* **Interactive Night Sky Canvas:** Twinkling starfield, subtle shooting stars, and a cursor star-trail effect outside cards[cite: 21].
* **Smooth Animations:** Scroll-reveal transitions, hero typing effect, scroll progress bar, and 3D tilt + spotlight hover cards[cite: 21].
* **Interactive Tech Stack:** Filterable skills section across *Languages*, *Systems & Net*, and *Core CS*[cite: 18].
* **Contact & Quick Actions:** One-click email copy with toast notifications, validated contact form, and social links[cite: 18, 21].
* **Fully Responsive:** Mobile-friendly navigation and layout[cite: 18].
