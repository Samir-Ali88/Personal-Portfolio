# SOLO — Samir Ali Portfolio

A dark night-sky personal portfolio built with **HTML5**, **Tailwind CSS**, custom CSS animations, and **Vanilla JavaScript** — ready for GitHub Pages.

## Recommended Portrait Size
- **Dimensions:** `800x800 px` (or `1000x1000 px`), **1:1 square** aspect ratio
- **File size:** Under `250 KB` (JPG or WebP)
- **File path:** `images/ok me.jpg`

## Deploying to GitHub Pages
1. Copy your portrait `ok me.jpg` into `images/`.
2. Push all files inside `solo-samir-portfolio/` to your GitHub repository root.
3. Go to **Settings -> Pages**, select the `main` branch and `/ (root)` folder, and save.
